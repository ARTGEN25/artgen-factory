# Specs

Task specs live in this directory: one file per task, named `<task_id>.md`.

## Template

```md
# <task_id>

## Goal
One sentence describing the outcome.

## Inputs / Outputs
- Inputs:
- Files to create or change:
- Definition of done:

## Constraints
- Keep Cloud Shell light.
- No secrets in the repo.
```

## Usage

1. Read `STATE.md` and `docs/INDEX.md` first.
2. Open only the spec matching the current `task_id`.
3. Update `STATE.md` (and relevant memory file) after the task completes.
